# 本地时序视图

时序事实由分析 Agent 随 behavior-flow-v1 流程记录的 sequence 字段提供。冻结执行规则和标准样例以 pangea-agent 的 scene_flow.md 为准。

Agent 提供参与者、消息、真实方向、返回/异步、自消息、条件与循环，以及源码依据。结构使用 sequence-v1，不提供像素坐标、画布尺寸或路由。

宿主按声明的消息顺序与片段归属确定性排版并导出 SVG。缺少证据时保留待确认说明，不把业务步骤机械猜成函数调用或交互消息。展示侧诊断不改变 Agent 的原始记录或 Run 状态，也不启动新的分析会话。

历史已生成图保留为只读产物；旧任务缺少 sequence 时如实显示未提供。
